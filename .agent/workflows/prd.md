# PRD Workflow (Amkabot)

Ensures the project vision remains aligned with user needs and technical constraints.

## 1. Context Gathering
- Review user requests and existing artifacts.
- identify the core business value (e.g., "predictive skill tracking").

## 2. Drafting
- Define **Success Metrics** (e.g., logic coverage, UI latency).
- Document **User Personas** (The Alpha Seeker, The Systematic Trader).
- Map **Key Features** to technical phases.

## 3. Verification
- Validate technical feasibility with a `language_comparison.md` or `stack_evaluation.md`.
- Ensure the PRD adheres to the Rich Hickey philosophy (Simple over Easy).

## 4. Output
- Save as `prd.md` in the brain directory.
- Request user review via `notify_user`.
